# Автоматизация тестирования мобильного приложения (Appium + Java)

Данный проект представляет собой тестовый фреймворк для автоматизации мобильного Android-приложения **Alfa-Test**. 

## 🛠 Стек технологий
* **Язык программирования**: Java 21
* **Инструмент автоматизации**: Appium (Java Client 9.3.0)
* **Тестовый фреймворк**: JUnit 5
* **Сборщик проектов**: Gradle
* **Логгирование**: SLF4J + Logback
* **Отчетность**: Поддержка Allure Framework

## 🏗 Архитектура и паттерны
В проекте реализован паттерн **Page Object Model (POM)**:
* `src/test/java/pages/` — Page Objects, описывающие элементы экрана и действия с ними.
* `src/test/java/tests/` — Тестовые классы, использующие Page Objects для выполнения проверок.
* **BasePage**: Инкапсулирует инициализацию элементов и логику явных ожиданий (`WebDriverWait`).
* **BaseTest**: Управляет жизненным циклом драйвера, загрузкой конфигураций и параметрами запуска.

## 🧪 Реализованные проверки
* **LoginTest** (`@Tag("smoke")`): Позитивный сценарий успешной авторизации.
* **LoginNegativeTest**: Параметризованный тест для проверки входа с неверными учетными данными (логин/пароль).
* **LoginValidationTest**: Параметризованный тест для проверки пустых полей ввода.
* **PasswordVisibilityTest**: Проверка работы переключателя маскировки пароля.
* **ExtremeDataTest**: Проверка обработки длинных строк (50+ символов) и контроль лимита ввода в полях.

## ⚖️ Приоритизация
Тесты запускаются в определенном порядке для обеспечения логической последовательности проверок:
1. LoginTest
2. LoginValidationTest
3. LoginNegativeTest
4. PasswordVisibilityTest
5. ExtremeDataTest
